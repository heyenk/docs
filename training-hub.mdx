            \<div id="lss-intro" class="bg-white p-8 rounded-2xl shadow-sm border border-stone-200 mb-8"\>

                \<h4 class="text-2xl font-bold mb-4 text-stone-800"\>Introduction to Lean Six Sigma (LSS)\</h4\>

                \<p class="text-stone-600 mb-6"\>This module introduces the fundamental concepts of Lean and Six Sigma. These methodologies are powerful tools used by organizations worldwide to improve processes, reduce waste, enhance quality, and ultimately drive business growth. Understanding these principles is the first step towards developing a growth mindset focused on continuous improvement, where we see challenges not as roadblocks, but as opportunities to learn and make things better.\</p\>

                \<div class="grid grid-cols-1 md:grid-cols-2 gap-8"\>

                    \<div\>

                        \<h5 class="font-bold text-xl mb-2"\>What is Lean?\</h5\>

                        \<p class="text-stone-600 mb-3"\>Lean is a methodology focused on maximizing customer value while minimizing waste. It's about creating more value for customers with fewer resources. The core idea is to eliminate activities that don't add value from the customer's perspective.\</p\>

                    \</div\>

                    \<div\>

                        \<h5 class="font-bold text-xl mb-2"\>What is Six Sigma?\</h5\>

                        \<p class="text-stone-600 mb-3"\>Six Sigma is a disciplined, data-driven methodology focused on eliminating defects and reducing variation in a process. A process operating at "Six Sigma" level produces fewer than 3.4 defects per million opportunities.\</p\>

                    \</div\>

                \</div\>

                \<div class="mt-8 pt-6 border-t"\>

                     \<h5 class="font-bold text-xl mb-3 text-center"\>The Power of Integration & The 8 Wastes\</h5\>

                     \<p class="text-stone-600 text-center mb-6 max-w-3xl mx-auto"\>Lean Six Sigma combines the speed and efficiency of Lean with the quality and effectiveness of Six Sigma. Lean focuses on identifying and eliminating waste. A common framework for remembering the types of waste is **TIM WOODS**. Click each waste below to see a real-world example within Promowise.\</p\>

                     \<div class="accordion-container space-y-2 max-w-4xl mx-auto"\>

                        \<div\>\<button class="accordion-button w-full text-left font-semibold p-3 bg-amber-50 rounded-lg flex justify-between items-center hover:bg-amber-100 transition border border-amber-200"\>\<span\>Transportation\</span\>\<svg class="accordion-icon w-5 h-5 transition-transform" fill="none" stroke="currentColor" viewBox="0 0 24 24"\>\<path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M19 9l-7 7-7-7"\>\</path\>\</svg\>\</button\>\<div class="accordion-content"\>\<p class="p-4 pt-3 text-sm text-stone-600"\>\<b\>Promowise Example:\</b\> Unnecessary movement of information.                         \<div\>\<button class="accordion-button w-full text-left font-semibold p-3 bg-amber-50 rounded-lg flex justify-between items-center hover:bg-amber-100 transition border border-amber-200"\>\<span\>Inventory\</span\>\<svg class="accordion-icon w-5 h-5 transition-transform" fill="none" stroke="currentColor" viewBox="0 0 24 24"\>\<path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M19 9l-7 7-7-7"\>\</path\>\</svg\>\</button\>\<div class="accordion-content"\>\<p class="p-4 pt-3 text-sm text-stone-600"\>\<b\>Promowise Example:\</b\> Work-in-progress that is sitting idle.             container.innerHTML = '';

            quizData.forEach((q, index) =\> {

                    \</select\>

                \`;

                container.appendChild(questionBlock);

            });

        }

        

        function submitYellowBeltQuiz() {

            let score = 0;

            const questions = document.querySelectorAll('#yellow-belt-quiz-container select');

            

            if (Array.from(questions).some(q =\> q.value === "-1")) {

                 alert('Please answer all questions before submitting.');

                 return;

            }

            questions.forEach(select =\> {

                const selectedIndex = parseInt(select.value, 10);

                const correctIndex = parseInt(select.dataset.correctAnswer, 10);

                select.disabled = true;

                if (selectedIndex === correctIndex) {

                    score\+\+;

                    select.classList.add('correct');

                } else {

                    select.classList.add('incorrect');

                }

            });

            const percentage = Math.round((score / yellowBeltQuizData.length) \* 100);

            const resultsContainer = document.getElementById('yellow-belt-results');

            resultsContainer.innerHTML = `Your Score: ${score}/${yellowBeltQuizData.length} (${percentage}%)`;

            if (percentage \>= 90) {

                resultsContainer.innerHTML \+= '\<br\>\<span class="text-green-600"\>Congratulations\! You passed\!\</span\>';

                generateCertificate();

            } else {

                resultsContainer.innerHTML \+= '\<br\>\<span class="text-red-600"\>You did not meet the 90% passing requirement. Please review the materials and try again.\</span\>';

                resetYellowBeltButton.classList.remove('hidden');

            }

            

            submitYellowBeltButton.disabled = true;

            submitYellowBeltButton.classList.add('opacity-50', 'cursor-not-allowed');

        }
